# ABI gap probe, second round (2026-11-13)

Twelve read-only agents, one area each, built their own small fixtures at
-Onone, -O and -Osize (C at -O0, -O2, -Os, plus the flags each area
needs) and compared every view of a pinned release build (dev 58580ca's
analysis, binary `swiftdc-abi2`) with `llvm-objdump`, `dyld_info`, `nm`,
`swift-demangle`, the emitted `.swiftinterface` and `swiftdc lab`. Each
was told the first round's classes
([abi-probe-2026-11-13.md](abi-probe-2026-11-13.md)) so as not to repeat
them. The fixtures stayed in the scratchpad; none is committed. Findings
are as reported, each checked against the disassembly by its agent; a
fix re-reproduces its finding before it lands.

Areas: noncopyable types, property wrappers and macros, actors, strings,
collections, integer arithmetic, parameter packs and opaque types,
Objective-C runtime idioms, switch lowering, linker and optimizer
transforms, globals and thread-locals, stack frames and instrumented
builds.

## Cross-cutting classes, ranked

1. **A call takes arguments the binary bounds away** (WRONG, six areas).
   Every `Task {}` and `addTask` site renders
   `TaskPriority.rawValue.getter(arg0)` (self is the Optional buffer in
   x20; x0 is a leftover retain result). -Osize zero-formal mutating Array
   members take the caller's entry registers
   (`_customRemoveLast(self: arg0, arg0)`). A value-type `deinit` call
   takes a third, stale register. A call through `adrp/add x8; blr x8` to
   an in-image function is never bounded by its summary (`one_arg(3, 7)`)
   because only `branchTarget` fills `callTargets`. A stack probe
   (`___chkstk_darwin`) counts as writing x0-x18 and v0-v7 in the callee
   summary's read pass, so arguments read after it are dead and
   `bigf(x, 2.0)` renders `bigf()`. Sanitizer runtime calls take stale
   registers. The reverse also happens: positional layout trims a written
   but unknown trailing argument (`__asan_report_load8()`, register tail
   `one_arg()`), which should show `?`.
2. **Signedness on the wrong side of a compare** (WRONG, two areas).
   `cset lt` on UInt operands renders a plain `<`, which reads unsigned;
   `csel gt` on UInt renders the same text as `csel hi`; a UInt `>= 0`;
   UInt `<` Int (`cset lo`) renders a Swift mixed compare, which is
   mathematical; a `tbnz x, #63` sign-bit trap on a UInt renders
   `if (arg1 < 0)`, never true. The mirror of the `scvtf` fix (58580ca):
   the signed paths never check the operand's type.
3. **Code dropped, the rest rendered as if complete** (MISSING, six
   areas). A bounds-check trap after an unrelated `subs` is folded as an
   overflow guard (`hasArithmeticFlagSetter` accepts any flag setter in
   the block, not the last one). A C store with an extended index
   (`str w1, [x8, w0, sxtw #2]`) is dropped and the body then claims
   "pure computation". `objc_autoreleasePoolPush/Pop` and
   `objc_retainBlock` are hidden as runtime noise by name prefix. -O
   string interpolation drops its first literal segment (stored with
   `stp`). A computed-goto function's only `ret` is skipped. A static
   property's `modify` and a `_read` coroutine drop their `yield`.
4. **Wrong values, names and boundaries** (WRONG). UTF-16 CFString
   literals read as C strings (`@"héllo"` as `@"h"`). `objc_opt_new`
   renders `[[C alloc] init]` (it sends `+new`). A GOT data import passed
   by address renders as its value (`use(extVal)` for `use(&extVal)`).
   One `stp` split into two statements whose second reads the field the
   first wrote. An outlined fragment seeded `x8 = &result`. A C function
   under ASan named with the Swift error register (`if (error == nil)`).
   -O0/-Onone jump tables after a `ret` get function starts and render as
   functions (`sub_19c8 { trap() }`), listed by `xrefs --unreferenced`.
5. **Interface spelling** (WRONG). Subscript labels (`(_: String, as:
   A.Type)` for `(key: String, as t: T.Type)`); an existential metatype of
   a composition (`Base & P.Type` for `any (Base & P).Type`); a pack
   same-shape requirement and an associated type default dropped;
   `~Copyable` parameters without `borrowing`; members of an
   `extension where A: ~Copyable` printed with member-level suppression.
   Most are in the MachOSwiftSection fork's printer.
6. **Entries left unseeded** (DECLINED, the most common lost fact):
   multi-word loadable struct parameters, a setter's `newValue`, a
   non-mutating value getter's self (seeded x20, arrives in x0), structs
   with Int32 fields, indirect aggregates, `isolated` parameters
   (`withoutOwnership` keeps the word), parameter packs, closure
   parameters, String parameters, non-allocating inits, any function whose
   arguments are first read after a stack probe.
7. **Returns lost** (DECLINED/MISSING): every Int-returning subscript
   getter (`X.subscript.getter : (…) -> Int` mistaken for a function-typed
   property at Disassembler.swift:5923); tail calls to getters, runtime
   entry points and two-word results without `return`; two-word struct
   returns; addressors; `[super value] + 1`.
8. **Switch tables declined**: clang's `int` subject (`mov w8, w0` or
   `sub w8, w0, #k` before the table), a base hoisted above a loop, every
   -O0 table (index spilled), `__const` value tables.
9. **Unnamed**: defined data symbols (stores, `swift_beginAccess`,
   `swift_once` tokens), thread-local access, ObjC constant literals,
   `swift_task_create` body pointers, MainActor hops (this toolchain never
   emits `swift_task_getMainExecutor`), associated-type descriptors.
10. **Diagnostics**: identical-code-folded bodies cannot be found by the
    name every view prints (`-f sub_944`); a linker alias reported as
    identical code folding; raw registers in conditions the tracer proved
    (cbz/cbnz truthiness tests are not baked); `if (x9 overflow -3)`;
    funclet headers numbered differently from their resume comments.
