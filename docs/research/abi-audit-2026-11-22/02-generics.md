# Generic and metadata ABI closure plan

Scope is swiftdc dev at b404252 with the current working changes visible. Compiler references are to public Swift 6.4.2, pinned at 83eb12448e4323abbf81b0153dced2faff02d22f. The version matches the installed Swift 6.4.2 toolchain, but the Apple build identity differs. Installed arm64 macOS compiler artifacts are the implementation oracle. Audit is source-only and read-only. No compiler fixtures or repository tests were run. “Covered” below means a static implementation and a relevant test were located. Many fixture tests use IfPresent guards, so existence gives no evidence that they ran.

## Inventory and evidence

### G01 — Polymorphic entry and outgoing argument order (P0/P1)

**Partial, with explicit declines.** `Disassembler.swift:6853–7057` reconstructs hidden metadata and witness registers for unspecialized synchronous free functions. It requires full formal placement with nothing on the stack, a printable simple generic head, effectively one depth, and its all-metadata precondition. Requirement identities come partly from demangle nodes and partly from printed names. It declines direct formal sources which might fulfill requirements and most compound parameters for witness tracking. `ValueTracking.swift:1293–1308` seeds the resulting register dictionaries. `ABISourceLoweringTests.swift:379–392, 1070–1171` cover generic outgoing formal arity, GP metadata then table, and a metadata source negative. `GenericInputPresenceTests.swift:229–326` exercises explicit absence across production summary routes.

**Compiler rule.** The invocation generic signature emits shape classes first, canonical metadata/value requirements, then conformances that require witness tables. Fulfillment maps select what is already reachable through parameters, including exact generic lvalue metadata for nominal indirect self, inexact class and superclass metadata and thick metatype metadata, with type-erased ObjC class exclusions. Witness methods use Self metadata and Self table sources, ObjC thunks use Self, and pseudogeneric functions have erased sources. Early generic-lvalue metadata is emitted before remaining unfulfilled requirements. Ordinary formals precede polymorphic expansion, then context/error roles, then witness-specific trailing roles. Async expands through its own path. [GenProto.cpp enumerateGenericSignatureRequirements and PolymorphicConvention](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenProto.cpp#L215-L481), [ExpandPolymorphicSignature](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenProto.cpp#L4368-L4457), [GenCall.cpp expandParameters](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenCall.cpp#L1985-L2132), [async expansion](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenCall.cpp#L2300-L2378), [Fulfillment search](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/Fulfillment.cpp#L37-L341).

**Implementation.** Decode depth/index and dependent-member identity, same-type canonicalization, superclass/layout/same-shape constraints, protocol reference identity, and function representation into one shared typed ABI input. Represent each fulfilled role as a path from a proven source, each emitted role as an ordered argument. Distinguish relevant protocol descriptor/table eligibility from mere name lookup. Feed the same formal + hidden plan to entry seeds, call-site reads, tail calls, and rendering, with G02 result roles and the ordinary register/stack classifier. Keep callee body observations as corroboration. Withhold subsequent placements across an unknown-sized predecessor while retaining an independently proven prefix. Replace the current all-or-none helper only after both producers and consumers use the shared plan.

**Oracle and mutations.** Plain `f<T,U:P>(T,U,Float)`, repeated/same-type and associated-type constraints, `Box<T>` and `Box<T>.Type` fulfillment, bare `T.Type`, `T: Box<U>` superclass source, generic value receiver and nested generic method, pseudogeneric ObjC thunk where compiler supports it, marker and ObjC protocols before a table-bearing protocol, generic witness with distinct method type argument, register exhaustion with independent FP bank and spill. Mutate metadata provenance, formal-bank assignment, table identity, descriptor kind, and signature requirement order separately. Each mutant must lose only facts dependent on the changed premise.

### G02 — Archetype transport and formal indirect result roles (P0/P1)

**Partial, with explicit declines.** `Disassembler.swift:7366–7389,7517–7525,7565–7576` treats a bare/dotted generic token as a one-word address and declines ordinary placement for a generic tuple return. `IndirectResults.swift:26–49,286–334` is centered on incoming x8 use plus Swift/provider evidence. It does not express a mixed direct and indirect result or distinct ordinary GP/stack result-buffer roles. The pointer-width fact can remain correct while the pointer's meaning is wrong for a class archetype. Existing `IndirectResultOrderTests.swift:12–113` exercise x8 result ordering, alias and lost-spill negatives. `ABISourceLoweringTests.swift:630–653,827–845` exercise a metatype and x8 writes. `ResilientTypeTests.swift:11–92` exercise refusal to use guessed resilient field layout.

**Compiler rule.** `convertArchetypeType` has class-reference and fixed-size trivial layout branches and opaque/address-only cases. Formal parameter convention (address, inout, pack, direct using native parameter schema) and result legalization are independent. `expandResult` disables sret with more than one formal indirect result. `expandDirectResult` and `expandIndirectResults` choose the direct value and whether an indirect result can claim sret. A result's tuple spelling does not describe the flattened lowered plan. [GenArchetype.cpp convertArchetypeType](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenArchetype.cpp#L339-L426), [GenCall.cpp expandResult/expandIndirectResults](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenCall.cpp#L688-L764), [expandDirectResult](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenCall.cpp#L1094-L1168), [expandParameter](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenCall.cpp#L1820-L1869).

**Implementation.** Model each lowered result as a distinct direct component or result destination, with argument or target sret location, write evidence, and size where proved. Preserve value identity after calls only at the defined component. Distinguish direct references, borrowed opaque addresses, inout and pack payload arrays. Move result storage effects and entry/call role identification onto this plan. Hand async/typed error/coroutine composition to their owners through the same roles.

**Oracle and mutations.** `id<T>`, `id<T:AnyObject>`, `id<T:KnownSuperclass>`, generic associated type, `(T,Int)`, `(T,U)`, generic-containing fixed footprint tuples, nested results, plus imported resilient values. Require native execution and independently recorded destination/result observations. Mutate the ordinary result-buffer producer, x8 read/write and mixture of direct and indirect results independently. Decline whole return reconstruction if a component has an unknown producer or a conflicting write.

### G03 — Protocol witness dispatch, requirements and table representations (P1)

**Partial.** `Disassembler.swift:4550–4695,5118–5140` handles selected generic-function and class-context tables, direct lookup, and selected existential calls. It reads pointer-word offsets and supports a subset of sync function requirements. `MetadataSymbolizer.swift:442–532` claims concrete table entries and selected resilient witnesses. `ResilientWitnessIndex.swift:69–92,135–153` handles descriptor/bind-based resilient witness naming and intentionally declines generic/unknown cases. Async function pointer records need their own owner’s proof. `ProtocolWitnessCallTests.swift:15–49`, `WitnessTailTests.swift:10`, `ResilientWitnessNamingTests.swift:15–66`, `ABISourceLoweringTests.swift:882–996` cover selected forms.

**Compiler rule.** Witness methods require trailing Self metadata then Self table even where other polymorphic parameters are fulfilled from Self. A conformance descriptor may have resilient witnesses, a generic witness table, conditional requirements and pack descriptors. `emitWitnessMethodValue` accounts for conditional indirection, chooses relative or ordinary witnesses, and selects pointer-auth schema by synchronous, async or callee-allocated coroutine representation. Relative protocol witness tables are option-gated with default disabled, and actual target availability must be confirmed before claiming Apple production coverage. Associated/base conformance retrieval has its own ABI. [GenProto.cpp expandTrailingWitnessSignature](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenProto.cpp#L4444-L4457), [emitWitnessMethodValue and associated conformances](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenProto.cpp#L4541-L4688), [relative dispatch](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenProto.cpp#L3103-L3257), [IRGenOptions defaults](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/AST/IRGenOptions.h#L689-L698), [Metadata.h witness and conformance descriptors](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/ABI/Metadata.h#L1844-L1931), [conformance trailers](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/ABI/Metadata.h#L2840-L3053).

**Implementation.** Separate descriptor index/kind, table representation and pointer provenance, and abstract Self/method ABI. Validate table format and slot kind before following pointers. Resolve direct, inherited and associated paths through same-image and provider-qualified cross-image descriptors. Attach call signature only when its lowered witness plan is proven, and validate required Self provenance against actual physical locations rather than the tail of a heuristic scan. Use existing async/coroutine record decoders and auth handling as dependencies. Handle resilient default and instantiated witness identities independently of symbol naming.

**Oracle and mutations.** In-image and imported P inherited from Q, two requirements with identical lowered signatures, generic requirement methods with `Self.Associated`, conditional conformance `Wrapper<T>:P where T:Q`, resilient public P in provider with conformance in client, default witness, async/read/modify requirements, and option-gated relative table if available. Mutate table shape/header, slot units, Self metadata/table pairing, requirement kind, entry pointer to a data record, and same-spelled protocol in another module. Keep ambiguous dynamic dispatch unresolved.

### G04 — Value witness signatures, provenance and effects (P1)

**Covered per bounded cases, partial overall.** `MetadataSymbolizer.swift:117–174` and `Pseudo.swift:881–899,971–979` encode the eight required operations and three enum operations, arity and void behavior. `Disassembler.swift:4729–4820` recognizes metadata preceding value witness pointers from selected known locations, runtime-derived and stripped inputs. Required slots on proven metadata and guessed-shaped inputs have different guard strengths. Enum slot recognition uses same-metadata argument equality, with no independently verified enum-table kind in `slotName`; structural evidence for arbitrary stripped input is heuristic. This is a source-observed limitation, not a reproduced false positive. `ValueWitnessArgumentTests.swift:14–90`, `StrippedWitnessOracleTests.swift:26`, `ABISourceLoweringTests.swift:705–865` cover accessor/class/cache/GOT/associated cases, ABI arity and lost metadata. `ExistentialWitnessTests.swift:99` covers opaque existential metadata.

**Compiler rule.** Metadata header is followed by metadata at its address point, with VWT obtained through the header. Required witnesses have exact return/argument types, integer/tag widths, destination/source semantics and fixed layout fields. Enum witnesses are an extension. [Metadata.h TargetTypeMetadataHeader/getValueWitnesses](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/ABI/Metadata.h#L341-L389), [ValueWitness.def](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/ABI/ValueWitness.def#L97-L289), [GenOpaque.cpp witness invocation and operations](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenOpaque.cpp#L427-L500).

**Implementation and gates.** Use one witness schema to separate pointer return/destination alias, scalar tag and void, definite versus possible storage effects, copy versus take, and dynamic size/alignment/inline-packability. Track metadata identity and conditional enum evidence through all load variants. Distinguish structural guesses from proved VWT calls in probe and rendering. Exercise each ABI slot, flags/size loads, nontrivial/bitwise-copyable values and constrained associated types. Mutate metadata argument, missing enum flag or non-enum provenance, byte offset into fields/padding, destination/source swap, and non-metadata pointer-table decoy. Verify stale x0 is never published for void slots.

### G05 — Existentials, opened archetypes and boxes (P1)

Test `Any`, `AnyObject`, `any P & Q`, class-bound mixtures including ObjC protocol, constrained primary-associated-type existential, protocol existential metatype vs concrete metatype, inline and out-of-line payloads, Error and bridged objects, opened existential forwarded to generic free and witness methods. ### G07 — Packs, shape classes and generic value parameter ABI (P0 guard, P2 completion)

**Source-confirmed mismatch and missing general model.** `VTableIndex.swift:127–136` admits metadata offsets for any top-level generic class whose parameters all have key arguments and whose superclass is nonresilient, using one word per parameter starting at the immediate members offset. Pack and value exclusions appear only in the separate table guard at 171–185. A top-level key type pack can therefore cause its initial shape length to be named as parameter metadata, and shift all subsequent mappings. No binary reproduction was run. `Disassembler.swift:6871,6917–6932,7027–7053` accepts a narrow generic signature and has no typed pack shape/payload lowering. No pack ABI oracle located by current test-name search.

**Compiler rule.** Distinguish function-signature shape classes/metadata pack/witness pack roles from the descriptor key-argument array. The latter begins with lengths, then metadata/pack pointers, tables/table packs and values as defined by the actual descriptor version and flags. The compiler handles metadata/witness pack construction and element projection separately from formal value pack addresses. Swift public source contains generic value parameters. Check installed toolchain feature support before requiring a positive oracle, and record the supported mode or unavailable gate. [GenericContext.h key layout and pack descriptor](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/ABI/GenericContext.h#L59-L106), [GenericPackShapeHeader and descriptors](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/include/swift/ABI/GenericContext.h#L264-L349), [GenProto.cpp ordered generic signature](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenProto.cpp#L280-L317), [GenPack.cpp shape expression and pack metadata](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenPack.cpp#L157-L195), [metadata and witness pack building](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenPack.cpp#L457-L774), [value-pack storage projection](https://github.com/swiftlang/swift/blob/83eb12448e4323abbf81b0153dced2faff02d22f/lib/IRGen/GenPack.cpp#L1144-L1190).

**Implementation and gates.** Immediately require the plain-type descriptor proof for both metadata and table maps. Then generalize G01/G08 into shape-class identity, scalar vs pack metadata and witnesses, payload-address arrays, and scalar value roles with version-gated descriptor flags. ## Implementation sequence and exit criteria

1. Add G07 offset guard and paired negative. Implement a role-oriented signature/layout plan shared with the ordinary parameter and result classifiers. Populate G01/G02 for scalar/generic archetypes and fail per role when source facts stop. Preserve declared source arity even if a physical location is unproved.
2. Add G08 typed metadata, then integrate G03/G04 table and witness-slot models. Handle G05/G06 container/opaque/field identities using the same address and layout provenance. Expand G07 packs after shape and dynamic-array evidence is available. Specialization/reabstraction and async/throw/coroutine owners consume the same role types but choose the representation-specific signature paths.
3. For each fixture collect compiler SIL, IR declarations and call operands, emitted assembly/linked disassembly, table/descriptor contents when relevant, and native execution observations under -Onone, -O and -Osize. Cross-module fixtures compile provider/client independently with and without library evolution, preserve non-inlined boundaries, and compare named, stripped and debug-free inputs. Mark unavailable feature gates and record the compiler/target reason. Every supported role must have positive artifact evidence plus a mutation exercising the exact proof premise. For unsupported roles, assert explicit unknown and absence of misleading names in entry, outgoing, tail, indirect result, probe and rendered views. Required fixtures fail on absence and do not silently skip. Compiler flag branches such as relative tables need an independent support matrix. No reproduced bug or passing build/test is claimed by this audit.
