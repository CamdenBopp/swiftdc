# ABI gap probe, 2026-11-13

Twenty read-only agents each built small fixtures for one ABI area (Swift
-O/-Osize/-Onone, C and Objective-C -O0 to -Os, arm64 and arm64e) and
checked swiftdc at dev 6b3fd16 (release build) against the plain listing
of each build. WRONG is a fabricated or misattributed value, argument,
receiver or callee; MISSING is something silently dropped; DECLINED is a
`?`, acceptable. Every item was checked against the instructions by the
agent that reports it; none was reproduced here. True when written:
re-check against HEAD before relying on an item.

## Cross-cutting classes, ranked

1. **A call whose callee has no usable signature takes its arguments from
   whatever registers are live** (WRONG, eight areas). Outlined helpers
   that end in `br` through a vtable slot (`ldr x8,[x20]; ldr x8,[x8,#n];
   br x8`) read only x20 but get `(arg0, arg1)`; register tail branches
   (`br`/`braa`) to a resolved callee count the target and discriminator
   registers; subscript setters, `() -> ()` partial-apply forwarders,
   class-bound witness calls, setters and getters through cross-module
   dispatch thunks and import stubs, `Int._bridgeToObjectiveC`, `$defer`
   bodies that write x0 first, and `swift_getAtKeyPath`/`swift_setAt*`
   (absent from SwiftRuntimeSignatures) all take a stale register.
2. **An outlined fragment that writes no x0 is taken to produce x0**
   (WRONG): -Osize stack-protector fragments (`ldr guard; str; ret`,
   `cmp; ret`) render `c_out(OUTLINED_FUNCTION_1(), …)` and
   `return r0`; any -Osize function that takes a stack address.
3. **No noreturn model at -O2/-Os** (WRONG): a call to abort, exit or an
   in-image cold function ending in `bl exit` falls into the next block,
   so an abort path reads as continuing or returning 0.
4. **arm64e**: `aut*`/`pac*` are not identities and a pre-index load with
   a symbolic base (`ldr x9,[x8,#8]!`) loses both registers, so every
   Swift vtable and witness call is unnamed under arm64e.
5. **Receivers dropped** (MISSING): x20 still valid after a call
   (mutating struct methods at -Onone, -O class getters), metatype
   receivers (`type(of: self).init`, class funcs: one also WRONG, shown
   as `self`), by-value enum self, protocol-extension and generic-type
   methods (entries unseeded, metadata and witness tables shown as
   arguments), non-allocating inits.
6. **Value renders** (WRONG): -Onone typed array literals print raw bits
   (`[Int8] [-1]` as `[255]`, `[Double] [1.5]` as `0x3ff8…`); `scvtf` on
   a UInt operand as `Double(arg0)`; an `__int128` return as its low
   half; `argN` counting integer registers only where no signature exists
   (C, stripped Swift), while signed Swift counts source positions.
7. **Objective-C metadata**: non-fragile ivars (`_OBJC_IVAR_$` offsets)
   are never resolved, so subclasses of framework classes read
   `return ?` and raw stores; a flat-namespace bundle's class list bound
   to its own class empties `objc` (exit 0, against the empty-result
   rule); an optional protocol property is listed `@required`; direct
   block invokes lose returns and captures.
8. **Control and exits**: a merged throw is placed before the shared
   cleanup block it falls into (-Onone partial init); constant async
   returns render `return ?` though the exit value is proven; context
   escapes lose async returns; -Osize async functions report no
   suspension point.
